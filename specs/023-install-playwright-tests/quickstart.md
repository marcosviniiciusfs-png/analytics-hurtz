# Quickstart: testes Playwright

## Pré-requisitos

- Dependências do projeto instaladas.
- Nenhuma execução automatizada do app em andamento.

## Executar

```powershell
npm run test:playwright
```

## Resultado esperado

- O Electron abre o Hurtz Flow Studio.
- O teste confirma o Dashboard e os três cards de criação.
- A janela fecha e o comando termina com sucesso.

## Diagnóstico

Em caso de falha, consulte `test-results/`; os artefatos são locais e ignorados pelo Git.
