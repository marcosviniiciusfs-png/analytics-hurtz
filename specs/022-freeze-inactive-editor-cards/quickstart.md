# Quickstart de validação

1. Execute `node scripts/inactive-card-freeze-e2e-test.js`.
2. Confirme zero repinturas inativas durante cem inputs de Fundo do slide e Sombra/Overlay.
3. Confirme que o scroll responde durante a sequência.
4. Troque de slide e confirme uma única consolidação do card anterior.
5. Execute os testes existentes de desempenho, fundo e overlay.
6. Execute `npm test` e `npm run build`.
