# Checklist de requisitos

- [x] Conceito de projeto foi diferenciado dos agrupadores removidos.
- [x] Identidade pública não expõe UUID interno.
- [x] Matriz de papéis está definida.
- [x] Convite exige aceite.
- [x] Isolamento é validado no servidor.
- [x] Migração preserva registros existentes.
- [x] Retenção de 72 horas permanece válida.
- [x] Estados mobile e vazios estão definidos.
- [x] Restrições de segurança estão explícitas.
