# UI Contract: Creators Generation

- Um carrossel de cinco slides contém `hook, body, body, body, cta`.
- As assinaturas visuais têm pelo menos três valores distintos.
- A fila contém somente slides cuja composição exige imagem e que não têm imagem válida.
- O progresso é `concluídos / total elegível`.
- Um resultado só é aplicado quando seu token ainda corresponde ao estado atual.
- Falhas finais permanecem visíveis e podem ser tentadas novamente individualmente ou pela fila.
