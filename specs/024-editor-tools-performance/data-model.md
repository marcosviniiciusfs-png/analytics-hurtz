# Data Model

## Editor interaction sample

- `tool`: família do controle
- `controlId`: identificador do input
- `durationMs`: duração observada
- `activeSlideId`: card editado
- `inactiveMutationCount`: alterações observadas nos cards inativos
- `scrollResponsive`: resposta do painel após a interação
- `errors`: erros de página e console

Os dados são efêmeros e usados somente pelos testes.
