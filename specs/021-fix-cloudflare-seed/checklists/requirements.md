- [x] Persistência do projeto de teste no dashboard definida
- [x] Escopo e dependências identificados
- [x] Isolamento de contexto visual por slide definido
- [x] Teste de não contaminação entre prompts definido
- [x] Invalidação de cache de interpretação definida
- [x] Retry seletivo preserva imagens concluídas e reprocessa apenas slides pendentes
- [x] IDs estáveis e isolamento de falhas por tentativa foram definidos
