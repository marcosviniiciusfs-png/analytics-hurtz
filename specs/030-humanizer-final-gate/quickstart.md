# Quickstart: validar o Humanizer final

1. Execute o teste unitário do gate.
2. Confirme que o caso `Seu corpo não estragou. Ele mudou — hormônio, circulação, ritmo de vida.` é reprovado pela análise.
3. Confirme que o fallback remove o travessão sem alterar hífens ortográficos.
4. Execute o teste de copy exata e confirme igualdade integral.
5. Execute o smoke test completo.
6. Gere um carrossel normal no aplicativo e confira o relatório Humanizer salvo no estado.

Resultado esperado: copy gerada aprovada, copy protegida inalterada e nenhuma regressão estrutural.
