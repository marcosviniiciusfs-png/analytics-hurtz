# Assistente Hurtz — Voz para Ligações

Novo produto de atendimento telefônico com voz natural, contexto persistente e transferência para atendimento humano.

Este projeto terá ambiente Python independente do Assistente de Reunião. A base técnica escolhida é o Pipecat, que oferece pipelines em tempo real para:

- detecção de fala e interrupções;
- transcrição streaming;
- contexto e ferramentas do agente;
- síntese de voz;
- WebRTC, WebSocket e transportes de telefonia;
- métricas de latência e observabilidade.

Status atual: desenvolvimento pausado em 26/07/2026. A arquitetura e o scaffold foram preservados para retomada futura. A prioridade atual do Assistente Hurtz é o módulo `assistente-whatsapp/`.
