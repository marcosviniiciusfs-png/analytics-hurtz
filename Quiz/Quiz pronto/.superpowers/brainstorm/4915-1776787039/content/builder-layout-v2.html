Layout do Builder

Como o criador visual do quiz deve ser organizado?

A

Sidebar + Preview

Esquerda: Lista de blocos arrastáveis (perguntas, captura de e-mail, resultado).
Centro: Preview ao vivo do quiz.
Direita: Painel de edição do bloco selecionado.

Estilo Calendly/Typeform editor. 3 colunas.

B

Lista + Preview (Inlead-style)

Esquerda (40%): Blocos empilhados verticalmente, clicar para editar inline.
Direita (60%): Preview interativo do quiz que atualiza em tempo real.

Estilo Inlead. Simples, 2 colunas. Edição inline sem painel extra.

C

Preview Fullscreen + Drawer

Tela cheia: Preview do quiz em tamanho real como o lead veria.
Drawer lateral: Abre pela direita para editar o bloco atual.
Steps: Navega entre perguntas por bolinhas ou setas.

Máximo foco visual. Edição sob demanda.

Recomendação

Para uma plataforma de quiz mobile-first, recomendo Opção B (Inlead-style): é o modelo que o Inlead usa, funciona bem em telas menores, e a edição inline é mais intuitiva. O preview à direita garante que o criador sempre veja o resultado final.
